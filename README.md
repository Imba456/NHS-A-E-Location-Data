# NHS-A-E-Location-Data
410 NHS A&amp;E locations by NHS Region, LSOA and UK wards from 2020

This data used to live on data.world: https://data.world/robbin/nhs-ae-location-data

Different file formats are provided for convenience, do keep in mind not all fileformats can hold spatial data but they can be recreate from the latitude and longitudes.

Keep in mind that this data is from 2020, obtained from google URLs as listed in the data.
